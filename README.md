# Simple Interest Calculator

A lightweight Bash script project designed to calculate simple interest based on principal amount, annual rate of interest, and time period in years.

## Project Details
* **Project Name:** Simple Interest Calculator
* **Repository:** `mcino-Introduction-to-Git-and-GitHub`
* **License:** Apache License 2.0
* **Author:** IBM Developer Skills Network

## Usage
Run the Bash script directly in any Unix-like terminal environment:

```bash
bash simple-interest.sh
```
